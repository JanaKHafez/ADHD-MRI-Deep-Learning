================================================================================
ADHD CLASSIFICATION FROM STRUCTURAL MRI - INSTALLATION GUIDE
================================================================================

SYSTEM REQUIREMENTS
================================================================================
- Python 3.8 or higher
- CUDA 11.8+ (for GPU support, optional but recommended)
- At least 50GB free disk space (for data and models)
- 16GB RAM minimum (32GB+ recommended)


QUICK START (5 STEPS)
================================================================================

1. Clone Repository
   git clone https://github.com/JanaKHafez/ADHD-MRI-Deep-Learning.git
   cd ADHD-MRI-Deep-Learning

2. Create Virtual Environment
   python -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On macOS/Linux:
   source venv/bin/activate

3. Install Core Dependencies
   pip install -r requirements.txt

4. Install Segmentation Dependencies (Optional)
   pip install -r segment_requirements.txt

5. Download Data and Pretrained Models
   See "DATA & MODELS" section below


DETAILED INSTALLATION
================================================================================

STEP 1: Clone Repository
--------
git clone https://github.com/JanaKHafez/ADHD-MRI-Deep-Learning.git
cd ADHD-MRI-Deep-Learning


STEP 2: Create Virtual Environment (Recommended)
--------
Option A - venv (Python built-in):
  python -m venv venv
  venv\Scripts\activate          # Windows
  source venv/bin/activate       # macOS/Linux

Option B - conda (if you have Anaconda installed):
  conda create -n adhd_mri python=3.10
  conda activate adhd_mri


STEP 3: Install Python Dependencies
--------
Core packages (required for training/inference):
  pip install -r requirements.txt

Key packages installed:
  - torch>=2.0.0
  - monai[all]>=1.2.0
  - torchvision
  - nibabel>=5.0.0
  - numpy>=1.23.0
  - pandas>=1.5.0
  - scikit-learn>=1.2.0
  - matplotlib>=3.7.0
  - tensorflow
  - plotly
  - seaborn

Installation time: 5-15 minutes depending on internet speed


STEP 4: Install Segmentation Dependencies (Optional)
--------
Only required if using SynthSeg for brain segmentation:
  pip install -r segment_requirements.txt

Additional packages:
  - torchio>=0.18.90
  - scikit-image
  - imageio


STEP 5: GPU Support (Optional but Recommended)
--------
If you have NVIDIA GPU and want GPU acceleration:

Check CUDA version:
  nvidia-smi

Install PyTorch with CUDA support (replace 11.8 with your CUDA version):
  pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

Verify GPU is available:
  python -c "import torch; print(torch.cuda.is_available())"


DATA & MODELS
================================================================================

STEP 1: Download ADHD200 Dataset
--------
The ADHD200 dataset is publicly available but large (~500GB preprocessed)

Option A - Download via Script:
  python prepare_adhd_bids.py --download

Option B - Manual Download:
  1. Visit: http://www.adhd200.org/
  2. Register for access
  3. Download preprocessed images (NIFTI format)
  4. Place in directory: ADHD_BIDS/

Dataset structure should be:
  ADHD_BIDS/
  ├── sub-001/
  │   └── anat/
  │       └── sub-001_T1w.nii.gz
  ├── sub-002/
  ├── participants.tsv
  └── ...

STEP 2: Prepare Data
--------
Convert to BIDS format and create metadata:
  python prepare_adhd_bids.py

This creates:
  - ADHD_BIDS/participants.tsv (subject metadata)
  - Standardized directory structure


STEP 3: Download Pretrained Models
--------
Models are included in pretrained_models/ directory:
  - resnet_18.pth (ResNet18 weights)
  - resnet_50.pth (ResNet50 weights)
  - SFCN_age.p (SFCN age prediction)
  - SFCN_sex.p (SFCN sex prediction)
  - BrainIAC*.ckpt (BrainIAC model checkpoints)

If missing, download manually:
  https://github.com/JanaKHafez/ADHD-MRI-Deep-Learning/releases/download/v1.0/pretrained_models.zip
  
  Then extract:
    unzip pretrained_models.zip -d .

TROUBLESHOOTING
================================================================================

Problem: "ModuleNotFoundError: No module named 'torch'"
Solution:
  pip install --upgrade torch torchvision torchaudio

Problem: "CUDA out of memory"
Solution:
  - Reduce batch size in config
  - Use CPU: set DEVICE=cpu in scripts
  - Reduce input image size

Problem: "No such file or directory: ADHD_BIDS"
Solution:
  - Ensure data is downloaded and in correct location
  - Run: python prepare_adhd_bids.py first

Problem: "ImportError: cannot import name 'NIfTI'"
Solution:
  pip install --upgrade nibabel

Problem: GPU not detected
Solution:
  - Check NVIDIA drivers: nvidia-smi
  - Verify CUDA installation: nvcc --version
  - Reinstall PyTorch with correct CUDA version
